# Native content-only Apply

`tests/live/regress_native_apply.sh` uses one fresh, exact-source leased pair.
Both sides install the locked free Qi Blocks 1.5.2 archive. The repository never
declares managed code. WordPress REST writes the retained 47 standalone block
types and 50 instances, and Qi's REST writer saves their styles. The two
integration blocks remain owned by their future participant-declared scenario.

Eight target-local trash rows force all four target post/attachment identities
to diverge. Complete native reads before Apply, after Apply, after zero-write
repeat and after HTTP rendering retain physical post rows, every Qi option,
attachment metadata and URLs, featured-image references, and every upload's
hash, byte length and dimensions. The independent corpus reader compares the
entire body and ordered PHP style container. The HTTP reader checks all 204
emitted page selector frames and the complete stylesheet after independently
proven home and page bindings; it does not measure computed browser styles.

Each repository snapshot retains its own policy, complete state and media
catalog. Source and transferred target inputs are retained before target Plan
or Apply, so private failure diagnostics remain reviewable after automatic pair
teardown. The shared compiler and convergence reader compare all entities,
policy, effects, deletions and the entire media catalog without target filters.

The source's 333×211 crop is an explicit unselected witness. It appears in no
saved body, style or rendered HTML and is absent from native attachment metadata.
The target must retain the original and all seven metadata-owned native sizes,
while leaving that unused crop absent. Selected desktop/tablet/mobile custom
crops still require separate native Save/reopen and recipe evidence.

Run from a clean candidate with distinct available even/successor ports:

```bash
QI_APPLY_PAIR=<owned-pair> QI_APPLY_PORT1=<even-port> QI_APPLY_PORT2=<next-port> \
QI_APPLY_ZIP=<absolute-path-to-locked-1.5.2-zip> \
WPRISM_EXPECTED_SOURCE_SHA=$(git rev-parse HEAD) \
bash adapter-packages/qi-blocks/tests/live/regress_native_apply.sh
```

The runner prints the private evidence directory and only reports success
after admission and verified teardown. The offline owner exercises the full
block materialization path, hostile native/HTTP/receipt controls, private
transport admission, and the runner's actual snapshot operation with different
per-site media catalogs. This workflow leaves Qi experimental: editor
Save/reopen, widgets/templates, selected custom crops, concurrent native writes,
lifecycle/recovery, host promotion, other versions and combinations remain
outside its qualification.
