## Evidence impact map

Current v1 certification closure includes all of `agent/`, `cli/`, and
`sandbox/bin`, selected Make/test/conformance/pair files, compatibility
baseline, generator, and each subject's declaration/hook/test inputs. The
foundation correction adds all of `recovery/`. Consequently:

| Changed input | Current subject effect |
|---|---|
| `agent/**` or `cli/**` | every current subject bundle becomes stale |
| `recovery/**` or the closure-membership implementation | every promotion/recovery-consuming current subject becomes stale; conservatively every v1 subject is treated stale for this migration |
| `sandbox/bin/**`, selected shared harness/Make/pair inputs | every subject whose closure contains the changed helper becomes stale; the current broad closure generally reaches all subjects |
| one manifest/conformance entry/hook/required test | that exact subject plus generated registry/prose; cross-manifest grammar changes can affect the full pin set |
| compatibility baseline or capability generator | all generated platform claims and their consuming release gate |
| generated registry/docs alone | never restores authority; inputs must first be current and the projection regenerated by its owner |

## Foundation implementation evidence

- Native declaration grammar is isolated in `NativeActionCatalog`; the
  `NativeActions` executor remains a compatible facade.
- Code descriptor/config/compiler callers use the pure descriptor leaf instead
  of the target-mutation `Code` facade.
- Capability/provider runtime checks consume a pure version-range service and
  target-runtime inspection port; the WordPress adapter is outside the offline
  policy load graph.
- Capture cron suppression and scoped-option projection are Thread 3 leaves.
- Capture baseline/version effects cross `CaptureMutationPort`, implemented by
  `CaptureMutationBridge` only at the agent composition root.
- The agent-side AdapterObservation collector owns `$wpdb`, Journal, Pending,
  and policy reads; `AdapterObservationProjector` is a pure closed projector.
- Host target/environment/recovery contracts are stable leaves under
  `cli/src/HostContracts`; mutation/recovery modules no longer type against
  concrete environment/SSH implementations.
- `RecoveryProtocolCodec` is byte-compatible with the standalone recovery
  canonical codec, and `cli/duo` no longer loads `rollback-control.php`.
- `ReleaseSelection` and the host-safe `ArtifactTrustVerifier` enforce an
  independently pinned release-family digest. A changed archive plus matching
  adjacent manifest is rejected.
- Policy and compiled-artifact authoritative file writes use
  `AtomicFilePublisher`; the injected pre-rename fault preserves old bytes.
- `ScopedCertificationBundle` includes `recovery/**`.
